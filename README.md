# Watch Store Admin

Expo Web admin panel for managing the existing Watch Store Supabase catalog.

## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```

3. Configure Supabase

   Copy `.env.example` to `.env` and set `EXPO_PUBLIC_SUPABASE_URL` and
   `EXPO_PUBLIC_SUPABASE_ANON_KEY` for the existing Supabase project. The admin
   panel uses the existing `watch-images` Storage bucket.

The app uses Expo Router and the existing `watch-images` Supabase Storage bucket.
